# Auto Data Cleaner

An automated data cleaning and analysis web application built using
Python, Pandas, Flask, and OpenAI.

## 🚀 Live Demo

https://auto-data-cleaner-2ga5.onrender.com/

## 📌 Project Overview

Auto Data Cleaner allows users to upload CSV, XLSX, or XLS files
and automatically performs data cleaning and analysis.

## ✨ Features

- Upload CSV, XLSX, and XLS files
- Detect and handle missing values
- Remove duplicate records
- Convert numeric and date columns
- Standardize categorical data
- Detect statistical outliers
- Generate a cleaned CSV file
- Generate AI-powered business analysis
- Display data-cleaning results and insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Flask
- OpenAI API
- HTML
- CSS
- Git & GitHub
- Render

## 🔄 How It Works

1. Upload a dataset
2. Pandas processes and cleans the data
3. Data quality statistics are generated
4. AI analyzes the cleaned dataset
5. Results and business insights are displayed
6. Download the cleaned dataset

## 📊 Cleaning Operations

The application performs:

- Missing value handling
- Duplicate removal
- Data type conversion
- Text standardization
- Outlier detection

## 💼 Business Analysis

The application generates:

- Executive Summary
- Key Data Insights
- Performance Analysis
- Problems and Areas to Improve
- Business Recommendations
- Growth Opportunities
- Management Action Plan
- Data Limitations
